# quistquest.com

The website for **Quist Quest**, a turn-based strategy game for phones.

Plain static HTML and CSS. No build step, no JavaScript, no cookies, no analytics,
no trackers. Served by GitHub Pages.

## Pages

| Path | File |
|---|---|
| `/` | `index.html` |
| `/privacy/` | `privacy/index.html` |
| `/support/` | `support/index.html` |
| 404 | `404.html` |

## Local preview

    python3 -m http.server 8080
    # then open http://localhost:8080

## Screenshots

`img/` holds screenshots captured from the game repo (`natelindq/quist-quest`,
branch `next`) at phone size 390x844 using that repo's Playwright harness.
The game repo is read-only from here; nothing in it is modified.

## House rules

- No analytics, cookies, ad scripts or email-signup services.
- No App Store or Google Play badges until those listings actually exist.
- No reviews, quotes, ratings, press or player numbers unless they are real.
- Every image needs alt text.
- Claims on the site must be checkable against the game's code.
